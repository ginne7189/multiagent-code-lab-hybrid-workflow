# Hybrid Workflow Code Lab

Routing, Parallelization, Result Contract, Evaluator 반복과 사람 확인을 하나의 실행 흐름으로 연결합니다.

```bash
make install
make run-normal
make run-failure
make check
```

각 패턴이 어느 단계의 어떤 문제를 해결하는지 Trace에서 확인합니다.

이 저장소는 **소스코드 전용 실행 패키지**입니다. 역할·계약·정책과 패턴 조합을 문서로 설계하는 실습은 [Hybrid Workflow Harness 저장소](https://github.com/ginne7189/agent-harness-lab-hybrid-workflow)에서 진행합니다.
